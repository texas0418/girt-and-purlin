The Source

All of the code is public. Read it, run it on your own computer, or check how a count was made.

Where It Livesgithub.com/texas0418/girt-and-purlin
The EnginePlain JavaScript with nothing to install. A building description goes in and every post, board, panel and cut comes out. 29 framing and material rules sit in one file, each marked checked or not checked.
The DesignerPlain files with no build step. The 3D picture uses three.js, which is included in the code.
The TestsThe engine's counts are checked by tests worked out by hand. Run them with npm test.
Run It YourselfFrom the project folder: python3 -m http.server 8771, then open localhost:8771/app/.
